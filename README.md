# Chapter 5 – Integumentary Guided Notes

Student-facing interactive notes recreated from the provided eight-page chapter. Includes original diagrams, fill-in blanks, extended response boxes, digital annotation, autosave on the student's current browser, downloadable JSON backups, backup import, and print/PDF.

## Publish to GitHub Pages
1. Create a **public repository** (e.g. `integumentary-guided-notes`).
2. Upload `index.html` and the `assets/` folder (not just the ZIP).
3. Go to repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. GitHub provides the public Pages URL once deployment is complete.

## Important
Student work is stored only in local browser storage; it does **not** sync across devices and is not collected by the teacher. Use Save work to file to make a portable backup. Export or print completed answers when submitting an assignment. Browser storage may be cleared by school-managed devices.
